## 🌐 How to Deploy to Vercel via GitHub

Because this project uses standard vanilla HTML, CSS, and JavaScript with no build step:

1. **Push this project to your GitHub repository:**
   ```bash
   git init
   git add .
   git commit -m "feat: Aires Jhoy Giverola Personal CV Website"
   git branch -M main
   git remote add origin https://github.com/giverolaires/<your-repo-name>.git
   git push -u origin main
   ```

2. **Deploy on Vercel:**
   - Log into [Vercel](https://vercel.com) using your GitHub account.
   - Click **"Add New..."** → **"Project"**.
   - Select your repository (`<your-repo-name>`).
   - Leave Framework Preset as **"Other"** or **"None"** (since it's pure HTML/CSS/JS).
   - Click **"Deploy"**.
   - Vercel will deploy your CV in seconds.
